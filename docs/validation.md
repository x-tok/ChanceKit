## 本机真实 QQ

环境：macOS 26.6.2，Apple Silicon；官方 QQ package 版本 6.9.89-45758；NapCat 4.18.28。

本轮开始时，本项目的组件和 QQ 资料目录均不存在。用户正常退出桌面 QQ 后，应用从官方发布地址下载 NapCat，校验固定 SHA-256，从官方 QQ 创建运行副本，并在新的 `runtime/qq-profile` 中登录。没有读取旧 QCE 目录、旧令牌或数据库密钥，没有修改原 `/Applications/QQ.app`。

已确认：

1. 官方 QQ 检测、私有副本准备及本地 ad-hoc 签名通过。
2. 客户端显示了真实登录二维码，用户通过手机 QQ 确认登录。
3. 真实 OneBot 连接返回 193 个群聊。
4. 一个招聘相关群最初成功读取 31 条消息，后续刷新与向前分页后累计归档 197 条。
5. 最后一批向前查询返回 99 条，新增 67 条；重叠消息没有重复落库。
6. 对比查询验证 `reverse_order=false` 返回锚点及更晚消息，`true` 返回锚点及更早消息。实现已采用 true 向前回溯。
7. 停止连接后，应用管理的 QQ 运行进程退出；重新打开客户端后恢复了本应用内刚确认过的登录，群列表和已归档数据保留。
8. 图像消息保留了真实 QQ HTTPS 图片引用。没有下载全量附件或调用模型服务。
9. 已生成 macOS arm64 `.app`，用独立临时数据目录启动打包后的应用，窗口及 utilityProcess 响应正常。

真实监听连接收到过 OneBot 心跳；一次 15 秒的额外观察窗口没有收到新群消息。实时消息入库、去重和断线重连已通过协议模拟服务验证，不把心跳当成真实新消息入库证据。
