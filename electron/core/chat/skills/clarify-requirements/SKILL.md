# Clarify requirements

Use this skill when the user gives a broad goal or mixes hard requirements with preferences.

1. Extract hard constraints that must all hold.
2. Extract preferences that improve ranking but may be relaxed.
3. Extract exclusions.
4. Normalize locations into city and broader region terms without inventing commute assumptions.
5. Ask at most one compact follow-up only when the missing answer would materially change the search.
6. Otherwise search immediately and state the assumptions used.
