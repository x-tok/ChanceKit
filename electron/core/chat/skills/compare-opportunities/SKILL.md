# Compare opportunities

Use this skill after search results exist.

Compare candidates on the same dimensions:

1. Location fit.
2. Company or organization fit.
3. Role and work-content fit.
4. Candidate audience, internship or graduation-year fit.
5. Application route and deadline completeness.
6. Source recency and evidence quality.

Do not turn missing data into a negative fact. Mark it as `未注明` and suggest what the user should verify. Identify each result by its real title, organization, date and source group. Never assign numbered opportunity labels. Use Markdown tables when helpful.

Distinguish local evidence, search snippets and read webpages. Select only relevant retrieved candidates with `select_chat_results`, and cite exact returned web URLs for online claims.
